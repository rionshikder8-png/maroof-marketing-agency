# MAROOF MARKETING AGENCY: Website

Premium five-page static website for Maroof Marketing Agency (Saad Rasheed, Pakistan).
Pages: `/`, `/services`, `/portfolio`, `/about`, `/contact` (+ `404.html`).

- **Stack:** plain HTML/CSS/JS generated by a zero-dependency Node script (`build.mjs`). No framework, no runtime dependencies.
- **Fonts:** Manrope (display) + Inter (body) via Google Fonts, with system fallbacks.
- **3D hero:** CSS 3D transforms (perspective + pointer tilt). No WebGL required, so there is nothing to fail. Honors `prefers-reduced-motion`.
- **Inquiry form:** no backend. It validates, builds a formatted message and opens WhatsApp (`wa.me/923190482228`). The visitor must press Send. The page says so explicitly and never claims an inquiry was received.

## Commands
```
npm run build   # generates ./dist
npm run check   # validates links, assets, anchors, titles, descriptions, WhatsApp number
```

## Deploy to Render (Static Site)
1. Render Dashboard -> **New + -> Static Site** -> connect this GitHub repo (branch `main`).
2. **Build command:** `npm run build`  **Publish directory:** `dist`
3. Name the service **`maroof360`** to get `https://maroof360.onrender.com` (only if the name is free; Render subdomains are first come, first served).
4. (Or use **New + -> Blueprint**; `render.yaml` holds the same settings.)

## Replacing assets
- **Logo:** header/footer use `assets/img/logo-mma-light.png` (transparent, white wordmark for dark backgrounds). `assets/img/logo-mma.png` is the transparent original for light backgrounds. To rebrand, replace both (PNG/SVG, proportions are preserved) and refresh favicon/OG images.
- **Portfolio:** concept artwork lives in the `concept()` / `PROJECTS` definitions in `build.mjs`. All are labeled "Concept Project". Replace them with real work when available.
- **Contact details:** constants at the top of `build.mjs` and `WA_NUM` in `assets/js/main.js`.
